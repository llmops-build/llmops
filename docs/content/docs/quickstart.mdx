Get started with LLMOps in minutes. This guide will walk you through installing the SDK, configuring providers, and making your first API request.

## Prerequisites

- Node.js 18+
- An API key from at least one supported provider (e.g. OpenAI, Groq, Google)

<Steps>
<Step>

### Install the SDK

```bash tab="npm"
npm install @llmops/sdk
```

```bash tab="pnpm"
pnpm add @llmops/sdk
```

```bash tab="yarn"
yarn add @llmops/sdk
```

</Step>

<Step>

### Set environment variables

Create a `.env` file with your provider API keys:

```bash title=".env"
OPENAI_API_KEY=sk-...
GROQ_API_KEY=gsk-...
```

</Step>

<Step>

### Create the LLMOps configuration

Create a file called `llmops.ts` to configure LLMOps:

```typescript title="llmops.ts"
import { llmops } from '@llmops/sdk';

export default llmops({
  basePath: '/llmops',
});
```

Providers are auto-detected from environment variables. You can also declare them explicitly:

```typescript title="llmops.ts"
import { llmops } from '@llmops/sdk';

export default llmops({
  basePath: '/llmops',
  providers: [
    { provider: 'openai', slug: 'openai', apiKey: process.env.OPENAI_API_KEY },
    { provider: 'groq', slug: 'groq', apiKey: process.env.GROQ_API_KEY },
  ],
});
```

</Step>

<Step>

### Create your server

Set up an Express server with the LLMOps middleware:

```typescript title="server.ts"
import 'dotenv/config';
import express from 'express';
import { createLLMOpsMiddleware } from '@llmops/sdk/express';
import llmopsClient from './llmops';

const app = express();
const port = 3000;

app.use(express.json());
app.use('/llmops', createLLMOpsMiddleware(llmopsClient));

app.listen(port, () => {
  console.log(`LLMOps running at http://localhost:${port}/llmops`);
});
```

</Step>

<Step>

### Start the server

Run your server:

```bash
npx tsx server.ts
```

Your LLMOps instance is now running at `http://localhost:3000/llmops`.

</Step>
</Steps>

## Making your first request

You can make requests using the OpenAI-compatible API with the `@slug/model` routing syntax:

```typescript
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'http://localhost:3000/llmops/api/genai/v1',
  apiKey: 'unused',
});

const response = await openai.chat.completions.create({
  model: '@openai/gpt-4o-mini',
  messages: [{ role: 'user', content: 'Hello!' }],
});

console.log(response.choices[0].message.content);
```
